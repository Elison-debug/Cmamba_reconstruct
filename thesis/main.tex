\chapter*{Abstract}
\addcontentsline{toc}{chapter}{Abstract}
This thesis investigates an end-to-end quantization workflow for a Mamba-based neural network, covering Python export, C++ reference inference, Python hardware-like simulation, and RTL validation. The work focuses on identifying quantization-sensitive components, defining reproducible case assets, and reducing hardware-oriented fixed-point error in the selective scan path through a scaled-state representation.
