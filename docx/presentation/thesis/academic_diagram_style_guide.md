# Academic Diagram Style Guide

This guide defines the shared visual style for thesis and paper diagrams.

## Overall Style

- Use a restrained blue academic style.
- Keep diagrams clean, sparse, and easy to read in print.
- Prefer simple rounded rectangles for process steps.
- Avoid decorative gradients, shadows, icons, and saturated colors.

## Color Palette

| Purpose | Color | Hex |
| --- | --- | --- |
| Primary stroke / arrow | Dark academic blue | `#2F5597` |
| Primary text | Deep navy | `#17365D` |
| Light node fill | Pale blue | `#EAF2FF` |
| Neutral node fill | Near-white blue | `#F7FBFF` |
| Emphasis node fill | Soft blue | `#DBEAFE` |

## Typography

- Font family: `Times New Roman`
- Node font size: `18 pt`
- Node font weight: bold
- Text color: `#17365D`
- Use short technical labels, preferably one line.

## Shapes

- Process step shape: rounded rectangle
- Border color: `#2F5597`
- Border width: `1.5 pt`
- Fill colors should alternate subtly between `#EAF2FF`, `#F7FBFF`, and `#DBEAFE`.
- Avoid heavy borders and drop shadows.

## Connectors

- Direction: top-to-bottom for sequential flows when space allows.
- Connector color: `#2F5597`
- Connector width: `1.5 pt`
- Arrowhead: filled block arrow
- Keep connectors straight and aligned to the center of each node.

## Layout

- Use vertical flow for model-to-implementation pipelines.
- Keep equal spacing between nodes.
- Align all nodes to a common center axis.
- Leave enough page margin for insertion into papers or slides.
