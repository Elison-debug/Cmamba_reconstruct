# RMSNorm `isqrt_u64` 原理说明

本文说明 [reuse_rmsnorm_scheduler.sv](/mnt/d/Mamba/CMamba_refactor/Cmamba_reconstruct/HW_reconstruct/rtl_reuse_shared/reuse_rmsnorm_scheduler.sv) 里 `isqrt_u64` 的计算方法，也就是整数平方根的按位试商法。

## 目标

`isqrt_u64(x)` 计算的是：

```text
floor(sqrt(x))
```

也就是不超过真实平方根的最大整数。

在当前 RMSNorm 里，它用于计算：

```text
rms_q88 = isqrt(mean_sq_q16 + eps_q16)
```

其中：

- `mean_sq_q16` 是 `Q16.16`
- 开根号后的结果 `rms_q88` 是 `Q8.8`

## 为什么平方根结果按 `2^k` 构造

因为硬件里的整数本来就是二进制表示：

```text
r = b0*2^0 + b1*2^1 + b2*2^2 + ...
```

所以平方根结果 `r` 也只能是一位一位地决定：

- 第 0 位要不要取 1
- 第 1 位要不要取 1
- 第 2 位要不要取 1

也就是说，平方根结果天然是按 `2^k` 这些位来构造的。

## 为什么 `step` 要按 `4^k` 选

假设平方根结果中某一位的权重是 `2^k`，那么它平方以后，对应到被开方数里的尺度就是：

```text
(2^k)^2 = 2^(2k) = 4^k
```

所以：

- 平方根结果按 `2^k` 构造
- 被开方数一侧的试探位就必须按 `4^k` 选

这也是代码里 `step` 每轮都右移 2 位的原因：

```verilog
step = step >> 2;
```

## 变量含义

在 `isqrt_u64` 里：

- `x`
  当前剩余的余量
- `res`
  当前已经构造出的中间结果
- `step`
  当前尝试的位级，始终是某个 `4^k`

注意：`res` 是算法内部使用的中间形式，不要简单把它理解成“最终答案的完整二进制表示”。算法结束时，`res` 才是最终整数平方根。

## `step` 的初始选择

代码里：

```verilog
step = 64'h4000_0000_0000_0000;
while (step > x)
    step = step >> 2;
```

其中：

```text
64'h4000_0000_0000_0000 = 2^62 = 4^31
```

它是 64 位范围内最大的 `4^k`。

这样做的目的不是“随便找个很大的数”，而是：

- 先从 64 位输入允许的最高合法试探位开始
- 再缩到不超过当前输入 `x` 的最大 `4^k`

例如如果 `x = 25`，初始 `step` 会不断右移 2 位，最后缩到：

```text
16 = 4^2
```

因为 `16 <= 25`，而下一个 `4^3 = 64 > 25`。

## 主循环规则

主循环是：

```text
while step != 0:
    if x >= res + step:
        x   = x - (res + step)
        res = (res >> 1) + step
    else:
        res = res >> 1
    step = step >> 2
```

可以这样理解：

- `x >= res + step`
  表示“当前这一位如果取 1，余量够不够”
- 如果够，就接受这一位
- 如果不够，就放弃这一位
- 然后继续试下一位

## 为什么判断是 `x >= res + step`

这是按位试商法整理后的标准递推形式。

含义可以直接理解为：

```text
如果当前位取 1，会增加一部分成本；
这个成本在当前递推里正好写成 res + step。
```

所以：

- 若 `x >= res + step`，说明这一位可以保留
- 若 `x < res + step`，说明这一位太大，不能保留

## 例子 1：`sqrt(25)`

目标：

```text
isqrt(25) = 5
```

先找不超过 25 的最大 `4^k`：

- `4^2 = 16`
- `4^3 = 64 > 25`

所以初始：

```text
x = 25
res = 0
step = 16
```

### 第 1 轮

判断：

```text
25 >= 0 + 16
```

成立，接受当前位：

```text
x   = 25 - 16 = 9
res = (0 >> 1) + 16 = 16
step = 16 >> 2 = 4
```

### 第 2 轮

判断：

```text
9 >= 16 + 4
```

不成立，放弃当前位：

```text
x   = 9
res = 16 >> 1 = 8
step = 4 >> 2 = 1
```

### 第 3 轮

判断：

```text
9 >= 8 + 1
```

成立，接受当前位：

```text
x   = 9 - 9 = 0
res = (8 >> 1) + 1 = 5
step = 1 >> 2 = 0
```

结束，得到：

```text
isqrt(25) = 5
```

## 例子 2：`sqrt(20)`

目标：

```text
isqrt(20) = 4
```

先找不超过 20 的最大 `4^k`：

```text
step = 16
```

初始：

```text
x = 20
res = 0
step = 16
```

### 第 1 轮

判断：

```text
20 >= 0 + 16
```

成立：

```text
x   = 20 - 16 = 4
res = 16
step = 4
```

### 第 2 轮

判断：

```text
4 >= 16 + 4
```

不成立：

```text
res = 8
step = 1
```

### 第 3 轮

判断：

```text
4 >= 8 + 1
```

不成立：

```text
res = 4
step = 0
```

结束，得到：

```text
isqrt(20) = 4
```

这正好等于：

```text
floor(sqrt(20)) = 4
```

## 总结

这套方法的关键点是：

- 平方根结果本身按二进制位 `2^k` 构造
- 映射到被开方数一侧后，对应的试探位是 `4^k`
- `step` 从最大的合法 `4^k` 开始，每轮右移 2 位
- `x` 表示剩余余量
- `res` 表示当前中间结果
- 每轮用 `x >= res + step` 判断当前位能否保留

因此它只需要：

- 比较
- 加减
- 移位

不需要浮点单元，也不需要复杂迭代器，非常适合定点硬件里的整数平方根实现。
